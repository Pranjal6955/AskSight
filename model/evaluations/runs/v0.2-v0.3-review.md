# v0.2 vs v0.3 model review

Checkpoint: `v0.3-vqa20k-cap10k`  
Evaluation date: 19 Nov 2026  
Training hardware: Tesla T4  
Test split fingerprint: `d8a3f0661b1c1708505f13cba7c630fc548cba83038ccac3c42e3a1744615707`

## Benchmark results

| Measure | v0.2-20k | v0.3-vqa20k-cap10k | Change |
|---|---:|---:|---:|
| VQA accuracy, same 1,014 test questions | 47.67% | 49.97% | +2.30 percentage points |
| Median latency | 0.267 s | 0.286 s | +7.1% |
| p95 latency | 0.333 s | 0.365 s | +9.6% |
| Process RSS | 3,975.1 MB | 3,975.0 MB | effectively unchanged |

The saved test predictions contain exactly the same 1,014 question IDs and the
same test fingerprint. On paired question scores, v0.3 did better on 120, worse
on 98, and tied on 796. A 10,000-resample paired bootstrap gives an approximate
95% interval of -0.2 to +4.7 points for the accuracy change, which includes no
change. Treat the gain as promising but not conclusive.

The rough question-type breakdown suggests the mixed caption training helped
counting (31.7% to 38.0%) and other questions (33.3% to 37.6%). Color accuracy
fell (31.0% to 28.7%); yes/no accuracy was nearly flat (71.6% to 71.9%). These
groups are simple keyword buckets, not official VQA categories.

Robustness accuracy was higher for v0.3 in every measured condition: blur
48.19%, dark 49.47%, obstruction 48.32%, and low resolution 49.47%. Blur and
low-resolution drops relative to v0.3 clean accuracy were 1.78 and 0.50 points.

## Fixed AskSight set

The set hash in the checkpoint metrics and Qwen3-VL output is
`d6093a3ea07928a4fdcb763bbf6491dd0b8fdd340a90d13619f858ccfdf57ee4`.
The original `asksight_v1.jsonl` is currently absent from `evaluations/`, though
both prediction files retain the questions, references, and description facts.

On the 18 direct VQA cases, accuracy was 42.6% for v0.2, 53.7% for v0.3, and
38.9% for Qwen3-VL-2B-Instruct under the strict VQA answer metric. Qwen often
answers in full sentences, which this exact-answer metric penalizes even when
the sentence contains the expected answer; use the description fact review as
the more relevant comparison for that model.

v0.3 still gives terse, incomplete descriptions. In the eight examples it
sometimes names the wrong main subject (“snowmobile” for the fire truck,
“stop sign” for a yellow “LOOK BOTH WAYS” sign), invents people in an empty
park, and adds an unsupported action to the dog photo. It describes the zebras
correctly, but usually omits useful secondary details.

Qwen3-VL provides more complete descriptions and correctly reads the yellow
pedestrian sign in this sample. It also adds details that need checking, such
as guessing the dog's breed and naming a flag in the night harbor. Its
recorded median/p95 latency was 0.854/6.608 seconds, with 29.91 seconds startup;
the saved Qwen metrics do not record the model revision or accelerator name.

## Recommendation

Keep v0.3 as the better VQA checkpoint so far, but do not treat the caption
training as a description-quality fix. The VQA gain is modest and uncertain,
and the description samples remain inadequate for the app. Qwen3-VL is a
stronger description candidate in this small review, with higher latency and
some unsupported details. Pin its model revision and evaluate more
consented, representative AskSight photos before choosing a serving model.
